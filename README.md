# 💊 Tablets

Персональный трекер приёма лекарств, дневник здоровья и напоминания.
**Kivy + KivyMD · SQLite · RU/EN · CSV/PDF-экспорт.**

> Never miss a dose — Tablets reminds, records and reports.

## ✨ Возможности

- 📋 **Лекарства** — название, дозировка, время, дни недели, курс, причина, заметки + автоподсказки из справочника при вводе
- ⏰ **Напоминания** — системные уведомления через `plyer` (исправленное окно срабатывания ±60 сек)
- ✅ **Действия в один тап** — кнопки «Принять / Пропустить» прямо в списке (повторный тап снимает отметку), иконки статуса, долгое нажатие для редактирования
- 📊 **Прогресс дня** — «Принято X/Y» с полосой + иконка в системном трее Windows (зелёная — всё принято)
- 📊 **Измерения** — 19 типов: вес, давление, глюкоза, пульс, температура, SpO2, анализы мочи, боль и др.
- 🤒 **Симптомы + подсказки** — 54 симптома с поиском, эвристический диагноз (ОРВИ/грипп/простуда/мигрень/ЖКТ/МВП/аллергия), короткие советы (макс. 2)
- 💊 **Подбор средств** — офлайн-справочник из 14 групп по симптомам (только информация, без дозировок!) + красные флаги; отдельный экран «Справочник» с поиском
- 🩺 **Доктор (ИИ)** — Ollama Cloud или локальный LM Studio на выбор, модели списком, тест соединения; без ключа/сети — офлайн-подсказки; к ответу всегда прикладывается подбор средств с кнопкой «В приём»
- 📖 **Описания лекарств** — карточки дополняются выдержкой из русской Wikipedia (CC BY-SA, с офлайн-фолбэком)
- 📈 **Тренды** — рост температуры 3 дня, высокий пульс 2 дня → уведомление
- 🎨 **Темы** — Blue / Pink (Material 3), мгновенное переключение
- 🌐 **RU / EN** — полная локализация, включая тосты и экспорты
- 📤 **Экспорт** — CSV (3 файла) и PDF-отчёт для врача, в `Documents/Tablets`
- 💾 **Надёжное хранение** — БД в `%APPDATA%/Tablets/tablets.db`, автосброс флагов раз в сутки, миграция со старой `medisafe_mvp.db`

## 🚀 Быстрый старт

```bash
git clone https://github.com/mrSaT13/Tablets.git
cd tablets
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
# source .venv/bin/activate

pip install -r requirements.txt
python main.py
# или:
python -m tablets  # нужен pip install -e .
```

> ⚠️ Требуется **Python 3.10–3.12**. На Python 3.13/3.14 у Kivy пока нет официальных wheels.

## 📦 Сборка Windows (.exe)

```bash
pip install pyinstaller
pyinstaller --name tablets --windowed --icon assets\app_icon.ico main.py
# Установщик:
# Откройте installer\tablets.iss в Inno Setup 6 → Compile
```

Готовые `.exe` **не хранятся в репозитории** — публикуйте их через
GitHub → Releases (см. `.gitignore`).

Для кириллицы в PDF положите `DejaVuSansCondensed.ttf` в `assets/fonts/`
(подробности — в `assets/fonts/README.md`). Без него будет использован
системный Arial, а в крайнем случае — Helvetica.

## 🩺 Доктор (ИИ, опционально)

Два провайдера на выбор (Настройки → «Провайдер ИИ»):

**Ollama Cloud** — нужен API-токен:
1. Получите ключ на [ollama.com](https://ollama.com).
2. Настройки → «Ключ Ollama Cloud» → вставьте ключ.
3. «Модель ИИ» — выбор из списка облачных моделей или своя.

**LM Studio (локально, без токена):**
1. Запустите [LM Studio](https://lmstudio.ai), загрузите модель, включите Server
   (по умолчанию `http://localhost:1234`).
2. Настройки → провайдер «LM Studio (локально)».
3. «Модель ИИ» → «Обновить список» — подтянет загруженные модели с сервера.
4. «Проверить соединение» — убедитесь, что всё отвечает.

Экран «Доктор» в меню: опишите симптомы → «Спросить».
Без ключа/сети Доктор отвечает офлайн-подсказками (диагноз + советы + средства).
ИИ не ставит диагноз и не назначает дозировки — это написано и в самом приложении.

## 💊 Откуда описания лекарств

- **Wikipedia RU** (встроено): карточка средства в справочнике/подборе
  автоматически дополняется выдержкой из русской Wikipedia
  (`ru.wikipedia.org/api` — бесплатно, без ключа, с офлайн-фолбэком).
- **Идеи для расширения** (англоязычные, официальные, бесплатные):
  - RxNav / RxNorm (`rxnav.nlm.nih.gov/REST`) — МНН, формы, взаимодействия;
  - DailyMed (`dailymed.nlm.nih.gov`) — официальные инструкции FDA;
  - OpenFDA drug label (`api.fda.gov/drug/label.json`) — состав, показания.
- Видаль/РЛС Leaf API не дают — парсить их не стоит (чужие данные, верстка
  постоянно меняется); лучше маппить МНН из RxNorm на русскую базу.

│   ├── exporters.py         # CSV/PDF с fallback-шрифтами
│   ├── notifications.py     # обёртка над plyer
│   └── config.py            # пути БД/экспорта, миграция со старой БД

├── assets/                  # иконки, wizard.bmp, fonts/README
├── installer/tablets.iss    # Inno Setup 6

## 🧪 Тесты

```bash
pip install pytest

```

Тесты покрывают чистую логику (`health.py`), БД (`database.py`)
и справочник (`drugs.py`) без запуска Kivy — быстро и стабильно.

## ⚖️ Правовая информация

- Приложение **не является медицинским изделием**, не ставит диагнозов
  и не назначает лечение/дозировки — только информация и напоминания.
  Все экраны со здоровьем содержат дисклеймер «посоветуйтесь с врачом».
- Все данные хранятся **локально** (`%APPDATA%/Tablets`), на сервер уходит
  только текст вопроса Доктору и только если вы сами ввели API-ключ.
- Выдержки Wikipedia используются по лицензии **CC BY-SA** с указанием источника.
